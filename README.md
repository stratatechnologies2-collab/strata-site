# Strata Technologies

Static website for Strata Technologies.

## Portfolio

The project grid lives in `portfolio.html`. Replace each `.placeholder` element
in a `.preview` panel with an `<img>` containing the finished project
screenshot. The live project links are already connected.

## Local preview

Open `index.html` in a browser, or serve this directory with any static file
server.

## GitHub Pages

The site is deployed automatically from the `main` branch using the workflow in
`.github/workflows/pages.yml`. After the first successful deployment, its
public URL is available in the repository's **Settings → Pages**.
